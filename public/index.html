Connectors

Connect the outside tools this app can use — BigTime for the budget gauge, Dropbox for meeting exports and documents, and a storage bucket for recordings. None of these are required; each is independent, and you can connect, change, or remove any of them at any time.

Changing a connector requires the connector admin password — this keeps anyone who just knows the site password from changing where your data goes.

BigTime

—

Powers the project budget gauge on the Dashboard, comparing invoiced-to-date against the total budget.

Where to find these: in BigTime, go to Firm Settings → API Access for your API Key and Firm ID.

Dropbox

—

Where meeting Word/PDF exports get saved, and powers the "+ Add document" picker on the Dashboard.

Getting a Dropbox connection set up takes one extra step beyond pasting in a key — see the README's Dropbox section for the short one-time authorization process. Once you have an App Key, App Secret, and Refresh Token, enter them below.

Recording storage

—

An S3-compatible bucket (Cloudflare R2 recommended) where meeting recordings are stored.

Where to find these: in Cloudflare, go to R2 Object Storage → Manage R2 API Tokens → Create API Token (Object Read & Write) for your Access Key ID and Secret Access Key; the Endpoint is shown on your R2 bucket's page.
